# Journal des choix

## 2026-11-10 – Installation de Node.js

- **Décision :** installer Node.js avec le dépôt NodeSource et apt.
- **Autres possibilités :** le paquet nodejs d'Ubuntu, le site nodejs.org.
- **Raison :** NodeSource donne la version LTS récente, et les commandes peuvent être refaites à l'identique dans mon README.

## 2026-11-10 – Système pour le terminal

- **Décision :** utiliser Ubuntu avec WSL.
- **Autres possibilités :** PowerShell, une machine virtuelle.
- **Raison :** WSL permet de taper les mêmes commandes que sur les serveurs, sans installer une autre machine.

## 2026-11-10 – Éditeur de code

- **Décision :** utiliser VS Code.
- **Autres possibilités :** nano, le Bloc-notes.
- **Raison :** VS Code s'ouvre sur les dossiers d'Ubuntu et a un terminal intégré.

## Hébergement du dépôt : GitHub

- **Décision :** J'ai choisi GitHub pour héberger mon dépôt Git.

- **Autres possibilités :** Je pouvais également utiliser GitLab ou Bitbucket.

- **Raison du choix :** GitHub me permet de sauvegarder mon projet en ligne, de conserver son historique et de collaborer facilement avec d'autres développeurs grâce aux branches et aux pull requests.
