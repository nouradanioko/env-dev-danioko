## Les outils réseau

| ----------------- | --------------- |
| `hostname -I`     | Affiche l'adresse IP de mon Ubuntu |
| `ping -c 4 <nom>` | Vérifie la connexion avec un ordinateur ou un serveur |
| `nslookup <nom>`  | Recherche l'adresse IP associée à un nom de domaine |
